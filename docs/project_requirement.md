만약 전체 화면이면 전체 화면 , 사용자가 선택한 영약이면 영역을 좌상, 우하 지점을 클릭하여 대상의 밤위를 정하고 , 
그범위가 정해지면, 화면 스크롤 포인트를 우 1개 정한다음 
스크롤을 정하는 입력한 시간(사용자 정함) 이 되었을 때 그 시간에 맞춰 화면을 스크린 캡쳐(300dpi, 100%화면 사이즈.jpg로 result 에 사용자 입력pdf제목_p[n].jpg , [n]은 패이지숫자, 일련번호로 자동저장 ) 하고 스크롤 포인트 눌러서 화면 좌측 하단에 진행 %를 보고 100% 가 되면 스크롤을 중단 하는 것으로 
캡쳐 가 다 완료 되면 전체 파일을 모두 PDF로 생성하여 사용자입력pdf제목.pdf 파일을 result 폴더에 저장한다.
