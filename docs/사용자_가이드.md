# ebook-capture 사용자 가이드

이 문서는 `ebook-capture`를 처음 쓰는 분을 위한 안내서입니다. 순서대로 그대로
따라 하면 됩니다. 개발자용 설명서(`README.md`)와 달리, 여기서는 낯선 용어가
나오면 그때그때 풀어서 설명합니다.

## 1. 이 도구로 할 수 있는 일

전자책 뷰어 화면을 자동으로 한 장씩 캡처하면서, 지정한 버튼을 대신 클릭해
다음 페이지로 넘겨줍니다. 결과물은 `result/` 폴더 안에 `<제목>_p001.jpg`처럼
번호가 매겨진 사진 파일들과, 그 사진들을 순서대로 묶은 PDF 파일 1개
(`<제목>.pdf`)입니다.

## 2. 처음 한 번만 하는 준비

### 2-1. 두 가지 권한 켜기

이 도구는 화면을 들여다보고 마우스를 대신 클릭해야 하므로, macOS가 두 가지
권한을 요구합니다. 아래 경로를 그대로 따라가서 켜 주세요.

**화면 기록 권한** — 없으면 캡처한 사진이 전부 새까맣게 나옵니다.

1. 화면 왼쪽 위 사과 메뉴 클릭 → **시스템 설정**
2. 왼쪽 목록에서 **개인정보 보호 및 보안** 클릭
3. 오른쪽에서 **화면 기록 및 시스템 오디오 녹음** (또는 **화면 기록**) 클릭
4. 목록에서 터미널(또는 이 프로그램을 실행할 앱, 예: VS Code)을 찾아 스위치를 켠다
   — 목록에 없다면 일단 프로그램을 한 번 실행해서 권한 요청 팝업이 뜨게 한 뒤 다시
   확인한다

**손쉬운 사용 권한** — 없으면 클릭이 전달되지 않고, `ESC`로 멈추는 것도
작동하지 않습니다.

1. 같은 **개인정보 보호 및 보안** 화면에서 **손쉬운 사용** 클릭
2. 목록에서 같은 앱(터미널 등)을 찾아 스위치를 켠다

**중요: 두 권한을 켠 뒤에는 그 앱(터미널 등)을 완전히 종료했다가 다시
열어야 합니다.** 창만 닫는 게 아니라 Dock에서 우클릭 → 종료(또는
`Cmd+Q`)까지 해야 권한이 실제로 적용됩니다.

### 2-2. 필요한 프로그램 설치

터미널을 새로 연 뒤, 아래 명령을 순서대로 입력합니다(각 줄을 치고 Enter).

```bash
brew install tesseract
uv pip install -e ".[dev]"
```

`tesseract`는 화면에 적힌 진행률 숫자(글자)를 읽어내는 데 쓰는 프로그램입니다.
사람이 눈으로 보고 "지금 30%구나"라고 읽는 걸 컴퓨터가 대신 하는 기능이라고
생각하면 됩니다(이 기능을 보통 OCR, 즉 "글자 인식"이라고 부릅니다).

### 2-3. 사전 점검 스크립트 돌리기

```bash
uv run python scripts/preflight.py
```

이 명령은 앞서 켠 두 권한이 실제로 잘 켜졌는지, 화면을 검게 캡처하지는
않는지, 클릭이 실제로 전달되는지를 미리 확인해 줍니다. 성공하면 화면에
권한 두 개가 모두 정상(예: `OK` 또는 `True`로 표시)이라는 메시지가 뜹니다.
만약 실패 메시지가 뜬다면 2-1로 돌아가 권한을 다시 확인하고, 반드시 앱을
재시작한 뒤 다시 시도하세요.

## 3. 캡처 전 준비 (여기서 최종 화질이 결정됩니다)

캡처는 화면에 실제로 보이는 그대로만 찍을 수 있습니다. 즉 화면에 있는
점(픽셀)의 개수가 곧 사진의 화질이고, 이 프로그램이 나중에 화질을 더
좋게 만들어 주지는 못합니다. 그래서 **캡처를 시작하기 전에 다음을 반드시
확인**하세요.

1. **전자책 뷰어를 갖고 있는 모니터 중 가장 큰(가장 해상도가 높은) 모니터에
   띄운다.** 여러 모니터가 있다면 4K처럼 해상도가 가장 높은 화면을 고릅니다.
2. **뷰어 창을 그 모니터 안에서 최대한 크게 키운다.** 실제로 측정해 보니,
   작은 창(1105×1776픽셀)으로 캡처했을 때는 PDF 페이지가 94×150mm(문고본
   정도 크기)로 나왔지만, 같은 4K 모니터에서 창을 최대한 키워서 다시
   캡처하니 페이지가 3200×2050픽셀이 되어 PDF도 271×174mm로 훨씬 커지고
   선명해졌습니다. **창을 크게 키우는 것이 화질을 올리는 유일한 방법**이라는
   뜻입니다. 나중에 설정으로 화질을 조정하는 방법은 없습니다.
3. 책을 **첫 페이지로 이동**시켜 둡니다.
4. 화면에서 **진행률(몇 %인지 보여주는 표시)이 보이는 위치를 미리 눈으로
   확인**해 둡니다. 보통 화면 구석에 작게 표시됩니다.

## 4. 실행 순서

아래 번호를 그대로, 순서대로 따라 하세요.

1. 터미널에서 다음을 입력하고 Enter를 누릅니다.

   ```bash
   uv run ebook-capture
   ```

2. `PDF 제목:`이라고 물으면 원하는 제목을 입력합니다. 이 제목이 그대로
   결과 파일 이름이 됩니다(예: `소설`을 입력하면 `소설.pdf`가 생성됩니다).
3. `캡처 간격(초):`라고 물으면 숫자를 입력합니다. **아직 이 값의 정답은
   측정되지 않았습니다** — 우선 `2`를 입력해 시작하고, 나중에 결과 사진을
   보고 같은 페이지가 두 장씩 겹쳐 저장되어 있으면 더 큰 숫자로 다시
   시도하세요. (자세한 확인 방법은 `README.md`의 "간격 정하기"에 있습니다.)
4. 화면에 "캡처 영역"을 지정하라는 안내가 나오면, **책 페이지의 왼쪽 위
   모서리**를 한 번 클릭하고, 이어서 **오른쪽 아래 모서리**를 한 번
   클릭합니다. (책 페이지의 네 귀퉁이 중 마주 보는 두 곳을 찍는다고
   생각하면 됩니다.)
5. 다음 안내가 나오면 **뷰어에서 다음 페이지로 넘기는 버튼(화살표 등)**을
   한 번 클릭합니다. 이 프로그램이 이후 이 위치를 계속 대신 클릭해 페이지를
   넘깁니다.
6. 마지막으로 "진행률(%) 표시 영역"을 지정하라는 안내가 나오면, 진행률
   숫자가 보이는 곳의 **왼쪽 위**와 **오른쪽 아래**를 클릭해 영역을
   지정합니다. **이 영역은 딱 맞게 좁게 잡을 필요가 전혀 없습니다.**
   진행률 글자 옆에 붙은 `%` 기호를 프로그램이 기준점으로 삼아 숫자를
   찾아내므로, 옆에 다른 글자(제목 등)가 조금 같이 들어가도 넉넉하고 크게
   잡는 편이 더 안전합니다.
7. `result/` 폴더에 생긴 `_preview_capture.png`와 `_preview_progress.png`
   두 파일을 열어서, 방금 지정한 영역이 실제로 원하던 곳(책 페이지 / 진행률
   숫자)과 맞는지 눈으로 확인합니다.
8. 터미널에 "미리보기가 올바릅니까? 계속하려면 y:"라고 뜨면, 맞으면 `y`를
   입력하고 Enter를 누릅니다. (영역을 잘못 잡았다면 `y` 대신 다른 아무 키나
   누르고 Enter를 눌러 취소한 뒤, 1번부터 다시 시작하세요.)
9. 5초 뒤 캡처가 자동으로 시작됩니다. **캡처가 끝날 때까지 마우스와
   키보드를 건드리지 마세요.** 프로그램이 마우스를 대신 조작하는 중이라,
   사람이 동시에 마우스를 움직이면 클릭 위치가 어긋날 수 있습니다. 이
   5초를 세는 동안에도 영역이 잘못됐다 싶으면 바로 `ESC`를 눌러 멈출 수
   있습니다(아래 5절 참고).

## 5. 중간에 멈추고 싶을 때

`ESC` 키를 한 번 누르면 즉시 멈춥니다. **캡처가 시작되기 전, "5초 후
시작합니다" 카운트다운이 도는 동안에도 `ESC`가 똑같이 동작합니다** —
미리보기를 보고 `y`를 눌렀더라도 카운트다운 중에 영역이 잘못됐다는 걸
알아챘다면 그 자리에서 `ESC`로 멈출 수 있습니다. 그때까지 캡처된
사진들은 지워지지 않고 `result/` 폴더에 그대로 남아 있습니다.

## 6. 결과물 확인

캡처가 끝나면 `result/<제목>.pdf` 파일이 만들어집니다. 터미널 화면에
`PDF 생성 완료: ... (n쪽, m MB)`처럼 쪽수와 파일 용량이 함께 출력되니
그 자리에서 바로 확인할 수 있습니다. 이 파일을 더블클릭하면 평소 쓰는
PDF 뷰어로 바로 열립니다.

## 7. 다시 이어서 하기

중간에 멈췄거나 실수로 중단됐다면, 처음부터 다시 클릭하지 않고 이어서
할 수 있습니다.

```bash
uv run ebook-capture --resume result/<제목>.session.json
```

앞서 지정했던 영역과 간격이 그대로 저장되어 있어서, 클릭 지점을 다시
찍을 필요 없이 바로 이어서 캡처가 시작됩니다. 이때 프로그램은
`result/` 폴더에 이미 저장된 사진 중 가장 마지막 번호를 찾아서, 그
다음 번호부터 새 사진을 저장합니다. 예를 들어 `내책_p010.jpg`까지
저장돼 있었다면 `내책_p011.jpg`부터 이어집니다. 앞에서 이미 찍은
사진은 전혀 건드리지 않으니 안심하고 이어서 진행하면 됩니다.

### 주의: `--resume` 없이 같은 제목으로 다시 실행하면

같은 제목으로 `--resume` 없이 다시 실행하면, 프로그램은 처음(1쪽)부터
다시 저장하려고 합니다. 그런데 `result/` 폴더에는 이미 이전에 찍은
사진들이 남아 있으므로, 그대로 두면 앞쪽 몇 장이 새 캡처로 덮어써져서
이전 캡처와 새 캡처가 한 PDF에 뒤섞이는 사고가 납니다.

이를 막기 위해 프로그램은 같은 제목의 기존 사진을 발견하면 아래처럼
경고를 보여주고 멈춥니다.

```
경고: '내책' 이름으로 이미 10쪽이 저장되어 있습니다.
  이대로 진행하면 앞쪽부터 덮어써서 이전에 캡처한 것과 뒤섞입니다.
  이어서 캡처하려면 --resume 을 사용하세요.
  기존 파일을 지우고 처음부터 시작하려면 d, 취소하려면 다른 키:
```

여기서 선택지는 둘 중 하나입니다.

- **이어서 캡처하고 싶다면**: 지금 실행을 취소(`d` 이외의 키)하고,
  위 6절에서 설명한 `--resume` 명령으로 다시 실행하세요.
- **정말로 처음부터 새로 찍고 싶다면**: `d`를 입력하세요. `d` 이외의 키를
  누르면 아무것도 지워지지 않고 그대로 취소됩니다.

**주의: `d`를 입력해도 기존 사진이 그 즉시 지워지지는 않습니다.** 그
다음에 미리보기 2장을 확인하고 "계속하려면 y"에 `y`를 입력해야 비로소
기존 사진이 지워지고 1쪽부터 새로 시작합니다. 즉, `d`를 입력한 뒤
미리보기를 보고 영역이 잘못됐다는 걸 알아채서 `y` 대신 다른 키를 누르면
`d`에 동의했던 것과 무관하게 기존 사진은 안전하게 그대로 남습니다.

## 8. 자주 겪는 문제

| 증상 | 원인 | 해결 |
|---|---|---|
| 캡처가 전부 검은 화면 | 화면 기록 권한 없음 | 설정에서 켠 뒤 **앱 재시작** |
| 클릭해도 페이지가 안 넘어감 | 손쉬운 사용 권한 없음 | 설정에서 켠 뒤 **앱 재시작** |
| 같은 페이지가 여러 장 저장됨 | 간격이 렌더링보다 짧음 | `--interval` 값을 늘린다 |
| 진행률이 "판독 실패"로 뜸 | 진행률 영역을 너무 좁게 잡음 | 다시 실행해 여유 있게 잡는다 |
| 끝났는데 마지막 몇 쪽이 없음 | 진행률이 100% 전에 정지 감지로 종료 | `--resume`으로 마지막 저장 페이지 다음 번호부터 이어서 진행 (기존 페이지는 그대로 두고 새 페이지만 추가됨) |
| PDF 페이지가 너무 작게 나옴 | 300dpi 메타데이터 기준 페이지 크기 | `--page-size a4` 사용 (화질은 동일) |
| 좌표를 잘못 잡았다 | — | 미리보기 확인 단계에서 `y` 대신 아무 키나 눌러 취소 |
| "이미 n쪽이 저장되어 있습니다" 경고가 뜸 | `--resume` 없이 같은 제목으로 다시 실행함 | 이어서 찍으려면 취소 후 `--resume` 사용, 처음부터 다시 찍으려면 `d` 입력 |

이 중 "끝났는데 마지막 몇 쪽이 없음"은 실제로 확인된 동작입니다: 뷰어에
따라 진행률 표시가 100%까지 정확히 올라가지 않고 99% 근처에 멈춰 있을 수
있는데, 이런 경우에도 화면이 더 이상 바뀌지 않으면(같은 화면이 3번 연속
찍히면) 프로그램이 "더 넘길 페이지가 없다"고 판단해 안전하게 멈추도록
설계되어 있습니다. 100%에 도달하든, 99%에서 멈추든 둘 다 정상적으로
캡처가 끝나도록 대비되어 있으니, 만약 마지막 페이지가 빠진 것 같다면
`--resume`으로 이어서 몇 장을 더 받으면 됩니다.

## 9. 화질에 대해 알아둘 것

캡처한 사진을 나중에 프로그램으로 확대(업스케일)해도 실제로 보이는
디테일은 늘어나지 않습니다 — 이미 없는 선명함을 새로 만들어낼 수는
없기 때문입니다. `--dpi`나 `--page-size` 같은 옵션은 PDF에 적힌
"페이지 크기 표기"만 바꿀 뿐 사진 자체의 화질에는 전혀 영향을 주지
않습니다. 화질을 실제로 올리는 방법은 3절에서 설명한 대로 **캡처 전에
뷰어 창을 가장 큰 모니터에서 최대한 크게 키우는 것, 그 한 가지뿐**입니다.
